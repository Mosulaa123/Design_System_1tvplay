04 Import Notes

Guidance for importing this styleguide into Figma via the html.to.design plugin.

1. Host this file. Push 1tvplay-styleguide.html to a GitHub repo and enable GitHub Pages. You'll get a public URL like username.github.io/repo.

2. Install html.to.design. From the Figma community. Open a new Figma file, run the plugin, and paste the GitHub Pages URL.

3. What imports well. All components render as nested frames with correct flexbox → auto-layout translation. Colors, typography scales, radii, and spacing arrive as raw values in a clean layer tree. Text uses the actual fonts (Noto Sans Georgian).

4. What needs manual work. CSS variables don't automatically become Figma variables — you'll need the Tokens Studio plugin to convert them, or do it manually. Components import as frames, not Figma component instances — you'll right-click and "Create component" on the ones you want reusable. Hover states are rendered statically side-by-side here specifically because html.to.design can't capture interactive states; pick the variants you want and promote them to component variants in Figma.

5. The mobile tab bar curve. The signature red curve under the active tab is an inline SVG path. It imports as a vector shape — editable in Figma's pen tool if you need to tweak the curve geometry.

6. Placeholder images. All card thumbnails use CSS gradients rather than external URLs — this keeps the import self-contained. Swap them with real assets once in Figma.
